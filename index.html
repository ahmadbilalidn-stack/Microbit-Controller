Deteksi Mobil dengan Kamera
Web mengirim nama kelas hasil deteksi ke Micro:bit persis seperti yang kamu tulis di Teachable Machine (misalnya mobil atau kosong). Data dikirim setiap kali kelas teratas berubah dan keyakinannya minimal 85%. Batas ini bisa dimatikan lewat saklar di bawah.

Kontrol Palang Parkir

Kirim perintah ke Micro:bit untuk membuka atau menutup palang.

Micro:bit mengirim masuk1, masuk2, masuk3 saat mobil masuk dan keluar1, keluar2, keluar3 saat mobil keluar (satu pesan per baris). Tombol di atas mengirim perintah mobil (buka) dan kosong (tutup). Semua data tercatat di System Activity Log.

Tentang Website

Microbit.Web adalah aplikasi web untuk menghubungkan BBC micro:bit memakai Web Bluetooth. Pantau sensor secara real-time, kendalikan perangkat dengan D-Pad, kirim hasil klasifikasi AI dari Teachable Machine, dan jalankan simulasi Smart Parking tanpa instalasi tambahan.

Web BluetoothMicro:bit UARTTensorFlow.jsTeachable MachineHTML · CSS · JS

Gunakan Chrome atau Edge; Web Bluetooth membutuhkan HTTPS atau localhost. Pintasan: Alt + 1–6 pindah menu.
